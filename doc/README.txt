FightGame 总体开发思路

1. 项目概述

FightGame是一款仿写拳皇97（KOF 97）的双人格斗游戏。

技术栈：Qt 6.11 / QML + C++23
构建系统：CMake 4.2.3
作者：Linfeng Wu

2. 技术架构

采用QML 渲染层 + C++ 逻辑层的双层架构，通过 Qt 的 Q_PROPERTY + 信号槽机制桥接。

QML渲染层（Main.qml / SelectScreen.qml / FightScreen.qml/StageSelectScreen.qml）
精灵表视口裁剪 + Scale 翻转
HUD（血条/能量条/倒计时）
键盘输入捕获
背景视差滚动

Q_PROPERTY + 信号

C++ 逻辑层（CharacterModel / FightDirector / CharacterConfig/appcontroller）
动画状态机（7状态循环）
战斗流程管理（开场→战斗）
跳跃抛物线计算
镜头跟随算法
JSON 配置解析

最后通过单例对象appcontroller启动应用程序和加载主界面

4. 数据驱动架构

所有角色动画参数通过config/characters.json配置：

json
{
    角色ID: {
        facingLeft: true/false,
        posX: 初始位置比例,
        opening: { "cols", "fw", "fh", "interval", "path" },
        stand:   { "cols", "fw", "fh", "interval", "path", "feetBottom", "feetMargin" },
        forward: { "cols", "fw", "fh", "interval", "path", "loop" },
        backward:{ ... },
        jump:    { ..., "jumpHeight", "visualScale" },
        diagonalJump: { ..., "jumpHeight", "jumpDistance", "divFrame", "visualScale" }
    }
}


新角色接入只需：准备精灵表图片 → 添加 JSON 配置 → 在 SelectScreen.qml 中注册角色条目。

5.未完成功能和缺陷
a.由于资源图和技术有限,该项目未能实现人物角色的特效技能
b.音频资源过于混乱和残缺,也没有给角色导入攻击声效和受击声效以及人物语音等
c.前期在设计和寻找动画资源花费了很多时间,还有后期给角色动作调整帧图和json参数也花费了很多时间,所以只完成了Yagami和Orochi这两个拳皇97比较经典的角色,在选人阶段只能选择这两个角色
d.联网方面也不是很成熟,两台机器之间的延迟虽然通过画面的平滑处理抵消,但是战斗时还是会出现一些动作不协调的地方,没有本地对战丝滑
e.由于Orochi的闪避机制和帧图有些特殊,我调了很久的参数但是还是会显得画面卡顿并且闪避前后和stand动作衔接不协调(备注:闪避字母键:方向键+J+K,数字键:方向键+1+2)
f.有些游戏机制也有待完善,比如没有对空机制,角色在起跳时是无敌帧状态,也没有空中攻击机制,这些都是因为没有相应的在空中受击后被击飞的帧图资源

6.由于我在调试人物动作的json参数和计算人物脚底位置都是以我的电脑屏幕为基础,使用最佳游戏体验屏幕分辨率为1920*1080(16:9),如果不是这个分辨率或者是这个分辨率但不是全屏的话,人物在做动作的时候可能会向下塌陷或者向上浮空,这些都是因为人物脚底位置计算的偏差
