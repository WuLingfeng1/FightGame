v0.1.9 — 下蹲系统、蹲防机制、攻击特效

日期：2026-06-18

变更摘要

实现下蹲系统和攻击视觉特效系统。Orochi 下蹲冻结 CrouchAttack.png 第0帧，Yagami 下蹲循环播放 Crouch.png。下蹲时被攻击不触发受击动画。轻拳命中时播放 3 帧攻击特效动画。

详细内容

下蹲系统：CharacterModel 新增 Crouch 和 CrouchAttack 两个状态。P1 按 S、P2 按 Down 进入下蹲。Orochi 使用 CrouchAttack.png 第0帧（冻结），Yagami 使用 Crouch.png 循环播放。下蹲时禁止移动、跳跃、攻击。

Yagami 下蹲帧图标准化：原始 Crouch.png（2304×512，6 帧 384×512）通过 Python 脚本 resize 为 1506×335（6 帧 251×335），与 Stand 帧尺寸完全一致，消除运行时缩放导致的卡顿和浮空。

Orochi 下蹲帧图提取：从 CrouchAttack.png（10 帧 384×512）提取第0帧 resize 为 251×335 保存为 Crouch.png，与 Stand 帧尺寸一致。

蹲防机制：playHurt/Hurt1/Hurt2/Hurt3 开头检查 m_crouching，下蹲时直接 return 不播放受击动画、无击退、无伤害。同时 QML 层所有攻击函数和 stopMove 函数增加 p1Crouching/p2Crouching 守卫，C++ 层 playStand() 增加 m_crouching 守卫，startCrouch 清除 movePressed 标记防止方向键释放打断下蹲。

攻击特效系统：FightScreen.qml 新增 attackVfx 组件，3 帧（1.png 15×21 / 2.png 27×23 / 3.png 32×31）每 50ms 依次播放后消失。缩放 fitScale×3.0。X 定位在两角色 30:70 加权中点，Y 定位在防御者视觉脖子处（positionY + frameHeight × (1 - visualScale × 0.8)），按角色和攻击类型微调偏移。

特效偏移量：Orochi 所有攻击 offset=-30，Yagami 拳类（state 7/9/11）offset=60，Yagami 腿类（state 8/10）offset=120（脚部）。
