# FightGame 语音资源对照表（MUGEN 还原版 v4）

按 **MUGEN 原版行为**逐状态还原 + 用户校准：

| 来源 | 说明 |
|---|---|
| Iori-ScarletMoon/Iori.snd | 八神庵（Yagami）喊声/命中音 |
| Orochi-ScarletMoon/Orochi97.snd | 大蛇（Orochi）台词/反馈音 |
| MUGEN data/common.snd | 系统挥击音（s5 组）、脚步音（s7 组） |

## 三种攻击音效的区别（用户校准）

1. **空放挥击音**（无碰撞）：攻击动作开始时播放的挥击音 = 系统 whoosh（s5 组），
   两角色**完全相同**；区别仅 Yagami 额外有人声喊声
2. **命中音**（碰撞测试触发）：攻击命中目标时播放，**每类攻击不同**：
   | 攻击类型 | 命中音 | MUGEN 出处 |
   |---|---|---|
   | 轻拳 | s12,0 | 状态 200 |
   | 轻腿 | s12,2 | 状态 230 |
   | 重拳 | s12,4 | 状态 250(吹飞系,加重) |
   | 重腿 | s9,6 | 状态 240 |
   | 超重击 | s12,7 | 状态 640 |
3. **攻击喊声**（仅 Yagami）：s6,12(轻拳)/s6,13(轻腿)/s6,4(重拳)/s6,11(重腿)/s6,16(超重击)

## 音量分层

挥击/命中 0.5~0.8 / 喊声 0.7 / 受击 0.8 / 脚步 0.7 / 开场·胜利 1.0

## 动作映射

### Yagami
| 动作 | 音源 |
|---|---|
| opening1~2 | s3,10+s3,5 / s3,12+s3,5 混音（190 状态台词，待用户确认替换） |
| punch/kick/heavyPunch/heavyKick/strike | 喊声 + 对应 swing*（系统 whoosh） |
| hurt | s1,6 + s6,1 呻吟 |
| jump/dodge | s6,13 喊声 + step（系统脚步） |
| win | s9,26 / s12,12 / s9,25 / s50,15 |
| hit* | 见上表命中音 |

### Orochi
| 动作 | 音源 |
|---|---|
| opening | s0,0+s0,1+s0,2 完整混音 5.2s |
| punch~strike | 无喊声，仅 swing*（与 Yagami 相同挥击音） |
| hurt | s7,3 命中反馈 |
| jump | s7,0 跳跃音 |
| dodge | 无（仅 step） |
| win | s0,3 / s0,4 / s0,5 |
| hit* | 与 Yagami 相同的命中音（KOF97 通用命中音） |

## 开场播放

- 动画末帧保持等待语音播完（characters.json `openingVoiceMs`：Yagami 3400 / Orochi 5200）
- 回合重置（resetForNewRound）跳过开场

## 代码接入点

- `fightdirector.cpp`：命中检测处播放 `hit`+攻击动作名（hitPunch/hitKick/...）
- `charactermodel.cpp`：attackAction() 返回当前攻击类型；开场保持逻辑
- `voicemanager.h/cpp`：动作分层音量
